# PnP 位姿估计

## 需求
已知标定板上角点的 3D 坐标与图像中的 2D 坐标，求相机相对标定板的 6DoF 位姿。

## 作用

- **机械臂手眼**：得到标定板到相机的变换，进而换算到机器人基座。
- **AR 注册**：把虚拟物体按位姿贴到平面上。
- **装配对位**：判断工件是否摆正、偏了多少度。

适用边界：必须知道相机内参（或至少知道大致焦距）；平面目标要避免完全正对，否则位姿病态。

## 核心函数
`cv2.findChessboardCorners()`、`cv2.cornerSubPix()`、`cv2.solvePnP()`、`cv2.solvePnPRefineLM()`

## 关键步骤
1. 检测 9×6 内角点并做亚像素细化
2. 按方格 25 mm 构造 3D 点阵
3. `solvePnP` 求初值，再用 `solvePnPRefineLM` 精修
4. 把坐标轴与一个立方体投影回图像，用重投影误差量化可信度

## 输入
一张棋盘格照片（`board.png`）

## 输出
带坐标轴与立方体的标注图，终端打印 rvec / tvec / 欧拉角 / 重投影误差

## 素材
`assets/board.png`：9×6 内角点、方格 25 mm 的棋盘格正视图。

## 运行
```bash
cd Python && python3 demo.py
python3 demo.py --square-mm 25 --display
```
依赖 OpenCV（含 contrib）+ NumPy。

## 演示结果
`output/pnp_axes.png`：棋盘格上叠了三轴与一个立方体，
顶部信息条给出 `t=(−100.2, −62.7, 418.6) mm`、三轴欧拉角约 0°，重投影误差 **0.022 px**。

## 实现要点
- **内参来源**：演示里按 `f≈1.2W` 假定内参，所以平移量是相对值；换成标定结果即得绝对位姿。
- **精度检验**：重投影误差是最直接的判据，0.02 px 说明角点与位姿高度自洽。
- **正视退化**：本例棋盘格几乎正对相机（欧拉角≈0），旋转分量其实是弱约束，
  实际使用应让板子倾斜 20°~40°，三个轴才都可观测。
