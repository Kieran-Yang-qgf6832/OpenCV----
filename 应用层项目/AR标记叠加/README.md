# AR 标记叠加

## 需求
识别 ArUco 标定板，解出相机位姿，在板上"立"起一个虚拟方块并随相机运动保持贴合。

## 作用

- **装配指引**：在工位实物上叠加虚拟标记/步骤提示。
- **展览互动**：纸质卡片上叠加 3D 模型。
- **标定可视化**：把估计出来的位姿画出来，肉眼验证是否合理。

适用边界：标定板要完整入画；快速运动会有抖动，需要位姿平滑。

## 核心函数
`cv2.aruco.detectMarkers()`、`cv2.solvePnP()`、`cv2.projectPoints()`、`cv2.fillConvexPoly()`

## 关键步骤
1. 每帧检测 3×3 板上的 9 个标记，按 ID 拼出板坐标系下的 3D 角点
2. `solvePnP` 解板相对相机的位姿，位姿用上一帧结果做指数平滑（系数 0.6）
3. 立方体 8 个顶点投影回图像，画三个面并按不同亮度填充（顶面/左面/右面）
4. 逐帧写入 H.264 视频

## 输入
`ar_scene.mp4`（100 帧，手持拍摄的 ArUco 板）

## 输出
叠加视频与关键帧

## 素材
`assets/ar_scene.mp4`：一块 3×3 的 `DICT_6X6_250` 标定板（id 0~8），相机缓慢移动。

## 运行
```bash
cd Python && python3 demo.py --display
python3 demo.py --smooth 0.6
```
依赖 OpenCV（含 contrib）+ NumPy。

## 演示结果
| 文件 | 内容 |
| --- | --- |
| `output/ar_overlay.mp4` | 立方体随相机贴合板面 |
| `output/ar_frame.png` | 中间帧 |

实测：100 帧中 **100 帧**成功解出位姿（100%），立方体始终贴在板面上。

## 实现要点
- **三个面分开填色**：同一个立方体画成三块不同亮度的多边形，才有立体感；
  全用同一颜色看起来就是个平面块。
- **平滑系数**：0.6 的指数平滑能压住检测抖动，但快速移动时会稍微"拖影"，可按需在脚本里调。
- **至少 4 个标记才解位姿**：单标记也能解，但平面法向会有二义性，多标记联合更稳。
