# 深度相机点云

## 需求
用相机内参把 RGB-D 数据反投影成三维点云，并在没有 3D 库的情况下把点云渲染成可看的图像。

## 作用

- **抓取前定位**：点云里量出物体的包围盒与高度。
- **堆垛/装载体积估算**：由点云统计堆积范围。
- **与 CAD 对位**：把实测点云与模型摆在一起比对。

适用边界：需要内参；深度图的边缘会有"飞点"，必须按深度范围过滤。

## 核心函数
`np.mgrid` 反投影、`cv2.applyColorMap()`、`cv2.circle()` 手写画家算法渲染

## 关键步骤
1. 读 16 位毫米深度图与对应的彩色图
2. `X=(u−cx)·Z/fx`、`Y=(v−cy)·Z/fy`、`Z=depth/1000` 反投影
3. 丢掉 0.2~8 m 之外的点，按步长降采样控制点数
4. 按深度从远到近排序后逐点绘制（画家算法），颜色用深度伪彩，输出两个视角

## 输入
`depth_rgb.png`（848×480 彩色）、`depth_map.png`（16 位，毫米）、`depth_intrinsics.txt`

## 输出
正视图 + 侧转 35° 的点云图及其拼接图

## 素材
`assets/`：程序合成的房间场景，彩色图与深度图严格对应；
内参真值 fx=fy=600、主点 (424, 240) 写在 `depth_intrinsics.txt`。

## 运行
```bash
cd Python && python3 demo.py
python3 demo.py --step 1 --display     # step=1 不降采样，点数 ×4
```
依赖 OpenCV（含 contrib）+ NumPy，不需要 open3d。

## 演示结果
| 文件 | 内容 |
| --- | --- |
| `output/pointcloud.png` | 正视图与侧转 35° 的并排渲染 |
| `output/pointcloud_front.png` | 单张正视图，便于放进文档 |

实测：**101 760** 点，包围盒 **7.76 × 4.38 × 3.54 m**，深度 2.83~6.37 m。

## 实现要点
- **颜色改用深度**：叠 RGB 纹理时画面信息很碎，按深度上色后墙面、近处方块一目了然。
- **画家算法足够用**：按相机系 Z 逆序逐点绘制即可，无需 z-buffer；点数超过 4 万时把半径降到 1 px。
- **飞点过滤**：深度 0（无效）与超远点必须先剔除，否则透视除法会把点甩到画面外。
