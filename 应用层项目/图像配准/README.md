# 图像配准

## 需求
把同一场景的变形图（旋转/缩放/透视）对齐回参考图，并给出配准的可信度。

## 作用

- **多时相比对**：同一机位的两次拍摄对齐后做差异检测。
- **文档校正/医学影像对齐**：把扫描件或重复拍摄摆正。
- **模板定位**：先配准再在统一坐标系里量尺寸。

适用边界：两图要有足够重叠与纹理；纯色区域多、或视角差异过大（>60°）时会失败。

## 核心函数
`cv2.SIFT_create()`、`cv2.BFMatcher.knnMatch()`、`cv2.findHomography()`、`cv2.warpPerspective()`

## 关键步骤
1. 两图各提 SIFT 描述子
2. 比值检验（0.75）筛匹配对
3. `findHomography(RANSAC, 3.0px)` 求单应，内点数即置信度
4. 用 H 把变形图映射回参考图，输出对齐结果、50% 叠加与内点连线图

## 输入
`scene.png`（参考）与 `scene_warped.png`（带旋转缩放的同一场景）

## 输出
三联图（待配准 / 对齐后 / 50% 叠加）与内点匹配连线图

## 素材
`assets/scene.png`、`scene_warped.png`：同一张街景，后者做了约 9% 缩放 + 小幅旋转平移。

## 运行
```bash
cd Python && python3 demo.py --display
```
依赖 OpenCV（含 contrib）+ NumPy。

## 演示结果
| 文件 | 内容 |
| --- | --- |
| `output/registration.png` | 待配准 / 对齐后 / 50% 叠加 |
| `output/registration_matches.png` | SIFT 内点匹配连线 |

实测：比值检验后 2173 对匹配，RANSAC 内点 **2120（98%）**；
解出的单应缩放 1.095、旋转约 1.8°，叠加图边缘无重影。

## 实现要点
- **内点率比匹配数更有意义**：匹配多但内点率低，说明有大量重复纹理在误导。
- **RANSAC 阈值**：3 px 对 1024 级图像合适；调太大会把错配也算进去。
- **单应的前提**：场景近似平面或纯旋转；有近景遮挡时应改用单应 + 分层或光流。
