# 实时绿幕抠图

## 需求
把绿幕背景实时替换成任意背景，并处理边缘绿边（溢色）。

## 作用

- **直播/短视频**：虚拟背景。
- **影视预演**：廉价绿幕替代摄影棚。
- **课件录制**：讲师抠像叠加到 PPT 上。

适用边界：背景要均匀绿、前景不能穿绿；自然光下的绿幕常有明暗不均，需要更复杂的键控。

## 核心函数
`cv2.inRange()`（HSV）、`cv2.morphologyEx()`、`cv2.GaussianBlur()`、`cv2.add`/`addWeighted`

## 关键步骤
1. HSV 里绿色色相区间 (35~95, S>90, V>40) 得到背景掩膜
2. 开/闭运算清边，再用高斯模糊把掩膜羽化成 alpha
3. 前景做绿边抑制：绿色通道不得超过红蓝通道的较大值
4. 按 alpha 与目标背景混合；左右并排写入视频

## 输入
`green_screen.mp4`（100 帧）与 `background.png`

## 输出
合成视频、关键帧、掩膜图

## 素材
`assets/green_screen.mp4`：纯绿背景前的一个红色物体；
`assets/background.png`：办公场景，用作替换背景。

## 运行
```bash
cd Python && python3 demo.py --display
```
依赖 OpenCV（含 contrib）+ NumPy。

## 演示结果
| 文件 | 内容 |
| --- | --- |
| `output/green_key.mp4` | 左原始 / 右合成 |
| `output/green_frame.png` | 中间帧 |
| `output/green_mask.png` | 背景掩膜（白=绿幕） |

实测：100 帧，平均抠掉 **97%** 的画面面积，物体边缘无明显绿边。

## 实现要点
- **绿边抑制是关键**：只做 alpha 混合会在物体边缘留一圈绿；
  把 G 通道压到 `max(R,B)` 之后边缘立刻干净。
- **羽化宽度**：9 px 高斯羽化能盖住锯齿，再大就会"漏背景"。
- **素材偏简单**：这份素材的绿幕非常均匀（97% 是纯绿），所以键控几乎是二值的；
  真实拍摄素材需要再加上下采样 + 局部阈值处理。
