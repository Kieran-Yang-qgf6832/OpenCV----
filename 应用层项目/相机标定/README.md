# 相机标定

## 需求
由多张棋盘格视图求相机内参与畸变系数，并给出可信度指标（重投影误差）。

## 作用

- **测距/测量前置**：所有基于像素的尺寸换算都依赖内参。
- **去畸变**：广角镜头的桶形畸变会毁掉直线，标定后可矫正。
- **仿真与数字孪生**：虚实相机参数对齐。

适用边界：棋盘格要平整、方格边长要真实；视图姿态单一会导致焦距不可辨（见实现要点）。

## 核心函数
`cv2.findChessboardCorners()`、`cv2.cornerSubPix()`、`cv2.calibrateCamera()`、`cv2.undistort()`

## 关键步骤
1. 12 张视图逐张检测 9×6 内角点并亚像素细化
2. 联合标定，固定切向畸变与 k3（只解 fx/fy/cx/cy/k1/k2）
3. 用每张视图的重投影误差画柱状图，判断哪张视图拖后腿
4. 用结果去畸变，与原图并排对比

## 输入
12 张棋盘格视图（`calib_01.png` … `calib_12.png`，1024×768）

## 输出
角点检测概览、去畸变对照、逐视图误差柱状图

## 素材
`assets/calib_*.png`：程序合成的 12 个位姿，棋盘格 9×6、方格 25 mm；
内参真值在 `assets/intrinsics_gt.txt`（fx=fy=900，主点 512,384）。

## 运行
```bash
cd Python && python3 demo.py
python3 demo.py --pattern 9x6 --square-mm 25 --display
```
依赖 OpenCV（含 contrib）+ NumPy。

## 演示结果
| 文件 | 内容 |
| --- | --- |
| `output/calib_corners.png` | 两张视图的角点叠加 |
| `output/calib_undistort.png` | 原图 vs 去畸变 |
| `output/calib_errors.png` | 12 个视图的单视图重投影误差 |

实测：整体 RMS **0.395 px**，单视图 0.33~0.39 px；
与真值对比 fx 误差 **0.38%**、fy **0.30%**、主点 0.76 px / 1.62 px。

## 实现要点
- **平面目标的尺度歧义**：只用正视图或位姿太单一时，f 与物距可以同时放大十倍而重投影不变。
  早期用一组姿态接近的素材，标出 fx≈11900 这种离谱结果；后来把视图换成 ±30° 偏航、
  ±26° 俯仰、±18° 滚转，才收敛到 900 附近。
- **固定高阶畸变**：k3 与切向项在无畸变数据上会被噪声带飞，固定为 0 后 RMS 更稳。
- **逐视图误差**：只报总 RMS 会掩盖个别坏视图，柱状图能直接看出哪张该重拍。
