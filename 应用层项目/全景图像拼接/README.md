# 全景图像拼接

## 需求
把多张有重叠的普通照片拼成一张宽视角全景图。

## 作用

- **手机全景**：横向扫一遍即得宽幅照片。
- **场地巡检**：把多张局部照合成一张全景，方便整体标注。
- **拼接式测量**：大尺寸工件分段拍摄后拼成一整张再做检测。

适用边界：相邻图要有 30% 以上重叠与足够纹理；拍摄时尽量绕光心旋转，避免视差重影。

## 核心函数
`cv2.Stitcher_create()`、`stitcher.stitch()`

## 关键步骤
1. 读入三张有重叠的视图
2. `Stitcher(SCANS)` 内部完成特征匹配 → 相机参数估计 → 接缝搜索 → 多频段融合
3. 检查返回状态码，非 0 直接报错并给出原因
4. 输出全景、三张来源图，以及接缝梯度图用于检查重影

## 输入
3 张纵向构图、水平方向有重叠的照片（720×572）

## 输出
全景图、来源对照图、接缝梯度图

## 素材
`assets/pan_01.png` … `pan_03.png`：同一处山谷湖景的三段视图。

## 运行
```bash
cd Python && python3 demo.py
python3 demo.py --mode PANORAMA --display
```
依赖 OpenCV（含 contrib）+ NumPy。

## 演示结果
| 文件 | 内容 |
| --- | --- |
| `output/panorama.png` | 拼接结果 **1022×572**（相对单张宽度放大 1.4 倍） |
| `output/panorama_sources.png` | 全景 + 三张来源缩略图 |
| `output/panorama_seam.png` | 梯度图，接缝处若出现亮线即为重影 |

拼接状态码 **0（OK）**，三张图全部参与。

## 实现要点
- **SCANS vs PANORAMA**：素材是平面扫描式构图，用 SCANS 模式；球形全景用 PANORAMA。
- **失败要说话**：状态码 1/2/3 分别代表"图不够""配不上""相机参数估计失败"，
  直接打印出来比抛异常更容易定位。
- **接缝检查**：拼接成功不等于没重影，Laplacian 梯度图能把融合带暴露出来。
