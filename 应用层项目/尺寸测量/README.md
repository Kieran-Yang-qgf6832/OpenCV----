# 尺寸测量

## 需求
在没有标定板、只有一枚已知边长的 ArUco 标记的情况下，测出画面中目标的真实尺寸（毫米）。

## 作用

- **来料抽检**：卡片、垫片、标签的边长复核，不用停机拿卡尺。
- **包装尺寸登记**：拍到参照物即可换算长宽。
- **现场粗测**：图纸不全时先量个大概，误差 1~2% 够用。

适用边界：目标与标记必须近似共面，且镜头不能有明显俯仰畸变；标记边长写错，测出来就全错。

## 核心函数
`cv2.aruco.detectMarkers()`、`cv2.minAreaRect()`、`cv2.boxPoints()`

## 关键步骤
1. 检测 ArUco 标记，取四角像素坐标
2. 四条边取平均除以标记实际边长，得到 px/mm
3. 颜色分割目标，用最小外接矩形量出长边与短边的像素长度
4. 除以比例尺得到毫米尺寸，并把读数标在图上

## 输入
一张含参照标记与目标的照片（本例 `measure_scene.png`，1024×1024）

## 输出
标注图：标记框、目标外接矩形、双箭头尺寸线与毫米读数

## 素材
`assets/measure_scene.png`：画面里同时有 ArUco 标记（id=23）、蓝色目标卡片和一把刻度尺。
刻尺只作肉眼交叉验证，程序用的是标记边长（默认 50 mm，可用 `--marker-mm` 改）。

## 运行
```bash
cd Python && python3 demo.py
python3 demo.py --marker-mm 40 --display
```
依赖：OpenCV（含 contrib）+ NumPy。本机 `python3` 指向的环境没有 OpenCV，
验证时用的是系统解释器 `/usr/bin/python3`（OpenCV 4.6.0）。

## 演示结果
| 文件 | 内容 |
| --- | --- |
| `output/measure_result.png` | 标记框 + 目标框 + `145.3 × 80.6 mm` 读数 |
| `output/measure_mask.png` | 目标分割掩膜，检查阈值是否漏检 |

实测：标记按 50 mm 换算得到 **2.780 px/mm**，目标测得 145.3 × 80.6 mm。

## 实现要点
- **背景干扰**：背景是同色系浅蓝渐变，只按色相分割会把整幅图都圈进来；
  因此在色相之外再限制明度上限（V<95），只保留深蓝卡片。
- **标记兜底**：`detectMarkers` 至少要 4 个角点，检不到就直接报错退出，不猜比例。
- **取长边**：`minAreaRect` 的长宽与卡片摆放角度无关，画尺寸线时挑四条边里最长的那条。
