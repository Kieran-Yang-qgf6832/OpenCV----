# 文档文字定位

## 需求
在扫描文档里定位整页、文字行与单字，输出三级框选结果，供后续识别或版面分析使用。

> 说明：本机没有 Tesseract 引擎，Python 版 OpenCV 也不附带 OCR 识别模型，
> 因此这个选题**只做定位与切分，不做字符识别**，标题也据此从「OCR文字识别」改为现名。

## 作用

- **OCR 前置**：把行/字切出来再送识别，比整图直接送准确率高。
- **版面统计**：行数、行高、字数用于排版核对。
- **票据/表单结构化**：先定位字段区域，再按位置取值。

适用边界：印刷体、拍摄较正的文档；手写、艺术字与强透视会切不准。

## 核心函数
`cv2.adaptiveThreshold()`、`cv2.minAreaRect()`（估倾角）、水平/垂直投影切分

## 关键步骤
1. 灰度 + 自适应二值化（反向），得到墨迹
2. 用墨迹点的最小外接矩形估整页倾斜角，±10° 内做校正
3. 水平投影切出文字行（间隙 > 6 px 断开）
4. 行内垂直投影切出单字（间隙 > 3 px 断开）

## 输入
`document.png`（1024×1024 的文档照片）

## 输出
三级框选图（行框橙色 + 字框绿色）与二值图

## 素材
`assets/document.png`：含标题、正文多段的文档图像。

## 运行
```bash
cd Python && python3 demo.py --display
```
依赖 OpenCV（含 contrib）+ NumPy。

## 演示结果
| 文件 | 内容 |
| --- | --- |
| `output/text_layout.png` | 10 条文字行的框（L1…L10）与 93 个单字框 |
| `output/text_binary.png` | 用于切分的二值墨迹 |

实测：切出 **10 行、93 个字符块**，行高 34~66 px（标题行明显更高）。

## 实现要点
- **投影法够用且可控**：不用连通域，投影对中文这种字内笔画相连的文本更稳。
- **间隙阈值要区分方向**：行间通常 > 8 px，字间 3~6 px，两个方向用不同阈值。
- **倾斜估计的意义**：倾斜 2° 就会让长行切歪、行数虚增，所以先校倾角再投影。
