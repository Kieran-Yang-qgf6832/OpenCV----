# ArUco 标定

## 需求
不依赖棋盘格，用一块 ArUco 标定板的多张视图完成相机内参与畸变标定。

## 作用

- **产线相机自标定**：现场只有打印好的 ArUco 板，没有棋盘格也能标。
- **长焦/广角复核**：换镜头后快速重标一次，避免用旧内参算错尺寸。
- **多相机外参**：同一块板在多个相机里出现，可顺带求相机间相对位姿。

适用边界：标定板必须平整，标记边长/间距要写对；视图姿态越分散，内参越稳。

## 核心函数
`cv2.aruco.detectMarkers()`、`cv2.calibrateCamera()`、`cv2.undistort()`

## 关键步骤
1. 板子是 3×3 个 `DICT_6X6_250` 标记（id 0~8 按行排列），边长 40 mm、间隔 12 mm
2. 按 ID 把每个标记的四角映射到板坐标系，拼成一整块点集
3. 12 个视图联合 `calibrateCamera`，只解 k1/k2（切向与 k3 固定为 0，避免过拟合）
4. 输出内参、畸变、重投影 RMS，并与素材自带真值对比

## 输入
12 张标定板视图（`board_view_01.png` … `board_view_12.png`，1024×1024）

## 输出
去畸变前后对照图、四视图拼图、内参与真值的误差

## 素材
`assets/board_view_*.png`：程序合成的 12 个位姿（偏航 −30°~30°、俯仰 ±26°、滚转 ±18°），
内参真值写在 `assets/intrinsics_gt.txt`（fx=fy=900，主点 512,512）。

## 运行
```bash
cd Python && python3 demo.py
python3 demo.py --marker-mm 40 --gap-mm 12 --display
```
依赖 OpenCV（含 contrib）+ NumPy。

## 演示结果
| 文件 | 内容 |
| --- | --- |
| `output/calib_undistorted.png` | 第一张视图的去畸变前后对照 |
| `output/calib_montage.png` | 前 4 个视图的标记检测概览 |

实测：12 视图全部参与，重投影 RMS **0.495 px**；
与真值相比 fx 误差 **1.25%**、fy **1.21%**、主点 0.26 px / 1.39 px。

## 实现要点
- **必须按 ID 建物点**：标记顺序与位置一一对应，漏掉某个 ID 时该视图的角点会错位。
- **至少 4 个标记**：少于 4 个的视图直接跳过，否则板面点集太小、位姿不稳。
- **为什么固定 k3**：合成数据本身无畸变，放开高阶项会拟合噪声（曾出现 k3 幅值上百）。
