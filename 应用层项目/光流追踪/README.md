# 光流追踪

## 需求
用稀疏 Lucas-Kanade 光流跟踪特征点，同时给出稠密光流，直观展示画面整体运动。

## 作用

- **视觉里程计前端**：LK 跟踪是 VO/SLAM 里最常用的帧间匹配手段。
- **人群/车流分析**：点轨迹与运动方向分布。
- **视频防抖与插帧**：运动场是补偿的依据。

适用边界：大位移需要金字塔层数足够；纯色区域提不到可跟踪的角点。

## 核心函数
`cv2.goodFeaturesToTrack()`、`cv2.calcOpticalFlowPyrLK()`、`cv2.calcOpticalFlowFarneback()`

## 关键步骤
1. 首帧提 200 个 Shi-Tomasi 角点
2. 相邻帧 LK 跟踪，再反向跟踪一次做前后向一致性校验（误差 > 1 px 丢弃）
3. 每个点保留 25 帧拖尾，颜色随时间渐变
4. 右下角叠一个 Farneback 稠密光流小窗（色相=方向、亮度=速度），与主画面 45/55 混合

## 输入
`flow.mp4`（1280×720，25 fps，100 帧街景行人）

## 输出
带轨迹的视频、关键帧、末帧

## 素材
`assets/flow.mp4`：街道上多组行人朝不同方向走动，运动方向丰富。

## 运行
```bash
cd Python && python3 demo.py --display
```
依赖 OpenCV（含 contrib）+ NumPy。

## 演示结果
| 文件 | 内容 |
| --- | --- |
| `output/flow_tracks.mp4` | 彩色拖尾 + 稠密光流小窗 |
| `output/flow_frame.png` | 中间帧 |
| `output/flow_last_frame.png` | 末帧（轨迹最长） |

实测：100 帧，末帧仍被稳定跟住的特征点 **66 个**，平均帧间位移 **10.4 px**。

## 实现要点
- **前向后向校验**：只做单向 LK 时，遮挡边缘会产生"飞出去"的假轨迹；
  反向跟踪误差超阈值即丢弃，轨迹干净很多。
- **稠密光流压暗**：初版把 Farneback 结果直接铺满画面，整块高饱和色盖住内容；
  改为 1/4 大小的小窗 + 半透明混合，既能看方向又不挡画面。
- **点数衰减是正常现象**：行人走出画面、被遮挡的点会被淘汰，重新提点可维持数量。
