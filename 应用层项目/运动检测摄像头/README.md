# 运动检测摄像头

## 需求
模拟固定机位监控：用帧差法判断画面里有没有运动，并触发告警、记录事件。

## 作用

- **周界报警**：只在有人经过时唤醒后续识别，省算力。
- **录像裁剪**：按事件起止时间切片存档。
- **仓储监控**：传送带上缺件/错位也会产生帧差。

适用边界：相机必须静止、光照稳定；开关灯、相机抖动会整幅误报。

## 核心函数
`cv2.absdiff()`、`cv2.threshold()`、`cv2.dilate()`、`cv2.findContours()`

## 关键步骤
1. 相邻帧灰度差 + 阈值 25 + 膨胀，得到运动掩膜
2. 掩膜内轮廓面积累计超过 400 px 即认为有运动
3. 加 6 帧滞回（HOLD_FRAMES），避免告警在阈值附近闪烁
4. 画面上叠加 REC、红色告警边框、时间戳与运动面积；结束后画事件时间线

## 输入
`motion.mp4`（99 帧，25 fps，固定机位）

## 输出
告警视频、关键帧、事件时间线图

## 素材
`assets/motion.mp4`：走廊里目标从远到近移动，约第 20 帧进入画面。

## 运行
```bash
cd Python && python3 demo.py --display
python3 demo.py --threshold 25
```
依赖 OpenCV（含 contrib）+ NumPy。

## 演示结果
| 文件 | 内容 |
| --- | --- |
| `output/motion_detected.mp4` | 告警帧带红框与 `MOTION ALARM` |
| `output/motion_frame.png` | 告警中的一帧 |
| `output/motion_events.png` | 逐帧告警状态时间线 |

实测：99 帧（4.0 秒）中告警 **80 帧（81%）**，事件切换 **1 次**（第 20 帧 ON）。

## 实现要点
- **滞回是必须的**：没有滞回时，目标恰好停住会每秒产生几十次 ON/OFF 抖动，无法存档。
- **面积而不是个数**：单个目标被阈割成几块时，个数口径会虚高，累计面积更稳。
- **摄像头抖动的处理**：真实监控里风吹摄像头就有帧差，工程上要么先做稳像，要么把告警门限调高。
