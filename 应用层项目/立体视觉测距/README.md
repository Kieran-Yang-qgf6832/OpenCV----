# 立体视觉测距

## 需求
由左右两台已配准的相机构成双目，逐像素求视差并换算深度，实现无源测距。

## 作用

- **避障与测距**：比单目多了绝对尺度，不需要知道物体真实大小。
- **体积/堆高检测**：货车、料堆的三维尺寸。
- **辅助自动驾驶**：与激光雷达互补的低成本深度来源。

适用边界：需要严格极线校正；弱纹理、反光、纯色表面会大量丢点（本项目的方块正面就有少量空洞）。

## 核心函数
`cv2.StereoSGBM_create()`、`SGBM.compute()`、`cv2.applyColorMap()`

## 关键步骤
1. 读入左右视图与 `f`、`baseline`
2. SGBM（3WAY 模式、51 级唯一性约束、斑点过滤）计算视差
3. `Z = f·B/d` 换算深度图
4. 与真值视差逐像素对比，统计 bad-1px / bad-2px / 有效像素率，并在近处目标上算测距相对误差

## 输入
严格配准的左右视图（1280×720）+ `stereo_params.txt`（f=700 px，B=0.10 m）

## 输出
视差伪彩图、深度伪彩图、估计/真值/误差三联图

## 素材
`assets/stereo_left.png`、`stereo_right.png`：程序合成的房间场景，右相机沿 +X 平移 100 mm；
`stereo_disp_gt.png`：按 `f·B/Z` 计算的 16 位定点真值视差（×16），用于定量评估。

## 运行
```bash
cd Python && python3 demo.py
python3 demo.py --block 5 --display
```
依赖 OpenCV（含 contrib）+ NumPy。

## 演示结果
| 文件 | 内容 |
| --- | --- |
| `output/disparity.png` | 视差伪彩图（TURBO 映射到 0~40 px） |
| `output/depth_map.png` | 深度图 |
| `output/depth_compare.png` | 估计视差 / 真值视差 / 深度误差（0.5 m 满量程） |

实测：有效视差 **94.6%**，与真值相比 bad-1px **0.69%**、bad-2px **0.32%**、平均误差 **0.27 px**；
近处方块测距 **2.807 m**（真值 2.843 m，相对误差 **1.25%**）。

## 实现要点
- **必须用光轴深度**：射线投射渲染给出的沿射线距离 t 要乘 cos 才能当 Z 用，
  否则视差图会出现同心圆状的假梯度（本项目踩过这个坑）。
- **纹理要非周期**：规则棋盘纹理会让匹配锁定到错误位移上，改用多尺度随机纹理后 bad-2px 从 42% 降到 0.3%。
- **参数取舍**：`disp12MaxDiff=1` + 斑点过滤会把方块边缘少量像素判为无效，换来的是几乎没有离群点。
