# 图像修复应用

## 需求
按掩膜把老照片上的划痕、破损补上，比较 Telea 与 Navier-Stokes 两种修复算法。

## 作用

- **老照片数字化**：扫描件的划痕、折痕修复。
- **去除水印/杂物**：小面积遮挡物的移除。
- **缺陷修补**：工业图像用掩膜抹掉干扰再检测。

适用边界：只适合小面积缺损（掩膜占比几个百分点）；大面积缺失应改用 PatchMatch/深度学习修复。

## 核心函数
`cv2.inpaint()`（`INPAINT_TELEA` / `INPAINT_NS`）、`cv2.dilate()`

## 关键步骤
1. 读受损图与掩膜（白=待修复）
2. 掩膜先膨胀 3×3，让修复区覆盖伤口边缘的过渡带
3. 两种算法各跑一遍并计时
4. 自动定位破损最密集的 320×320 窗口，做局部放大对照

## 输入
`damaged.png`（1024×1024）与 `mask.png`（单通道）

## 输出
四联图（原图 / 掩膜 / Telea / NS）、局部放大图、掩膜图

## 素材
`assets/damaged.png`、`mask.png`：老照片与人工标注的划痕掩膜（占 2.14% 像素）。

## 运行
```bash
cd Python && python3 demo.py
python3 demo.py --radius 5 --display
```
依赖 OpenCV（含 contrib）+ NumPy。

## 演示结果
| 文件 | 内容 |
| --- | --- |
| `output/inpaint.png` | 原图 / 掩膜 / Telea / NS 四联 |
| `output/inpaint_crop.png` | 破损最密集处的三图放大 |
| `output/inpaint_mask.png` | 实际送入算法的掩膜 |

实测：待修复像素 **2.14%**，Telea **0.109 s**、Navier-Stokes **0.085 s**（1024×1024）。

## 实现要点
- **放大图要选对位置**：早期用掩膜质心定位，结果落在空白处看不出差别；
  现在用积分图找破损密度最高的窗口。
- **两种算法的差别**：Telea 用快速行进 + 邻域加权，边缘更锐；NS 解偏微分方程，过渡更平滑，
  细长划痕上 Telea 通常更自然。
- **半径的影响**：半径大于缺损宽度的一半才有足够信息，但过大会把周围纹理拖糊。
