# ArUco 检测

## 需求
检测画面中的 ArUco 标记，读出 ID，并估计每个标记相对相机的 6DoF 位姿。

## 作用

- **产线定位**：贴在工件托盘上的标记给出工位坐标。
- **机器人抓取**：一次识别多个标记即可得到多个候选抓取点。
- **相机外参初值**：已知标记布局时，可以直接反推相机姿态。

适用边界：标记要完整入画、对比度足够；强反光或过大倾角会让 ID 解不出来。

## 核心函数
`cv2.aruco.detectMarkers()`、`cv2.solvePnP()`、`cv2.drawFrameAxes()`

## 关键步骤
1. `DICT_6X6_250` 字典检测，拿到四角与 ID
2. 按“标记边长 40 mm”构造物点，用假定内参求解 `solvePnP`（`SOLVEPNP_IPPE_SQUARE`）
3. 用 `drawFrameAxes` 画出每个标记的三轴，位姿解不出来时退化为手画两条轴
4. 在标记中心标注 ID 与相机距离

## 输入
含多个标记的图片（`aruco_scene.png`，3×3 标定板光栅图）

## 输出
标注图：每个标记的边框、ID、距离，以及位姿坐标轴

## 素材
`assets/aruco_scene.png`：9 个 `DICT_6X6_250` 标记（id 0~8）的板面照片。

## 运行
```bash
cd Python && python3 demo.py
python3 demo.py --marker-mm 40 --display
```
依赖 OpenCV（含 contrib）+ NumPy。

## 演示结果
`output/aruco_detected.png`：九宫格标记全部检出，ID 依次为 0~8，
每枚标记上叠了三轴坐标，估计距离集中在 310~330 mm（同板共面，数值应接近）。

## 实现要点
- **内参假设**：没有标定文件时按 `f≈1.2W` 估计内参，所以距离是相对量；
  要绝对精度请改用「相机标定」或「ArUco标定」得到的内参。
- **四角顺序**：ArUco 返回的角点从左上开始顺时针，物点必须按同样顺序构造，
  否则 `IPPE_SQUARE` 会把位姿解成镜像。
- **按 ID 排序输出**：检测顺序与图像位置无关，打印前统一排序，便于逐条核对。
