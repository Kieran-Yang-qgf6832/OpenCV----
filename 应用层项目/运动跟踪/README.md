# 运动跟踪

## 需求
用稠密光流把"在动的像素"分割出来，并对最大的运动目标做框选与轨迹记录。

## 作用

- **运动分割**：不需要目标模型，只靠运动场就能分出前景。
- **行为分析**：运动矢量场给出整体流向。
- **异常检测**：与整体流向相反的局部运动往往是异常。

适用边界：相机必须静止；孔径问题会让纯平移的均匀纹理区域失去方向。

## 核心函数
`cv2.calcOpticalFlowFarneback()`、`cv2.magnitude()`、`cv2.findContours()`

## 关键步骤
1. 相邻帧 Farneback 稠密光流，得到每像素位移矢量
2. 位移幅度超阈值（1.2 px/帧）判为运动，开闭运算清理
3. 最大连通域 > 1500 px 的框选为目标，中心点记录成轨迹
4. 在网格点上画运动矢量箭头，并把运动像元占比压在左上角

## 输入
`motion_track.mp4`（99 帧，固定机位）

## 输出
带箭头、目标框与轨迹的视频，关键帧

## 素材
`assets/motion_track.mp4`：走廊场景中一个红色目标从画面左侧移动到右侧。

## 运行
```bash
cd Python && python3 demo.py --display
python3 demo.py --threshold 1.2
```
依赖 OpenCV（含 contrib）+ NumPy。

## 演示结果
| 文件 | 内容 |
| --- | --- |
| `output/motion_tracks.mp4` | 矢量箭头 + 绿色目标框 + 紫色轨迹 |
| `output/motion_frame.png` | 中间帧 |

实测：99 帧中 **80 帧**检出运动目标，轨迹横向位移 **1019 px**、纵向 −39 px，
与素材中目标横移的设定一致。

## 实现要点
- **阈值单位是像素/帧**：与帧率强相关，换帧率要重调；不然慢速运动会被当成静止。
- **为什么要闭运算**：目标内部纹理均匀时光流为零，掩膜会碎成环状，闭运算把它补实。
- **和「光流追踪」的区别**：本选题关心"哪块在动"（分割），
  「光流追踪」关心"某些点跑到哪了"（跟踪）。
