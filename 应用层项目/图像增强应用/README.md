# 图像增强应用

## 需求
把暗光、低对比的照片提亮到可读，并在三种增强方案之间做定量比较。

## 作用

- **夜间监控取证**：暗部细节提亮后才能看清人脸/车牌。
- **手机夜景**：对比度拉伸是 ISP 里的基础环节。
- **工业检测**：光照不均的场景先做局部对比度均衡，缺陷才显形。

适用边界：提亮不会增加信息；噪声会同步被放大，暗光图上应先降噪或加保边约束。

## 核心函数
`cv2.createCLAHE()`、`cv2.cvtColor(LAB)`、`cv2.LUT()`（gamma）

## 关键步骤
1. 读暗光图，计算增强前的平均亮度、对比度、信息熵、暗部占比
2. 三种方案：LAB 空间 CLAHE、gamma 校正、gamma 与原图混合
3. 同样的指标再算一遍，比较提升幅度
4. 输出四宫格对比图与三张亮度直方图（对数纵轴）

## 输入
`lowlight.png`（1024×1024 暗光书桌）

## 输出
四宫格增强对比图 + 直方图对照

## 素材
`assets/lowlight.png`：室内弱光拍摄（平均亮度只有 9.3/255）。

## 运行
```bash
cd Python && python3 demo.py
python3 demo.py --gamma 0.45 --display
```
依赖 OpenCV（含 contrib）+ NumPy。

## 演示结果
| 文件 | 内容 |
| --- | --- |
| `output/enhance.png` | 原图 / CLAHE / gamma / gamma+blend |
| `output/enhance_hist.png` | 三张亮度直方图（对数纵轴） |

实测（原图 → 最佳方案）：

| 方案 | 平均亮度 | 对比度 std | 信息熵 | 暗部占比 |
| --- | --- | --- | --- | --- |
| original | 9.3 | 20.9 | 4.23 | 96.1% |
| CLAHE(LAB) | 24.2 | 32.5 | 4.58 | 91.8% |
| gamma 0.45 | **39.8** | **35.4** | **5.64** | 84.2% |
| gamma+blend | 26.1 | 28.2 | 5.39 | 91.4% |

## 实现要点
- **CLAHE 只在 LAB 的 L 通道做**：直接对 BGR 三通道做会把颜色扳偏。
- **gamma 与混合的取舍**：纯 gamma 提亮最明显但亮部容易冲爆，`gamma+blend`
  按 55/45 混合，观感更自然。
- **直方图用对数纵轴**：暗光图 96% 的像素挤在 0~30，线性纵轴会把曲线压成一根刺。
