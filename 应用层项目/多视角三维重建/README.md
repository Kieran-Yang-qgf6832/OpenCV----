# 多视角三维重建

## 需求
用环绕拍摄的 6 个视角做稀疏三维重建：先恢复相机位姿，再三角化出点云。

## 作用

- **文物/产品数字化**：拍一圈得到可测量的点云。
- **SLAM 前端**：本质矩阵求相对位姿是视觉里程计的核心步骤。
- **缺陷记录**：把现场多角度照片还原成三维，方便回看。

适用边界：需要足够视差与纹理；纯平面场景本质矩阵退化，重建会失败。

## 核心函数
`cv2.SIFT_create()`、`cv2.findEssentialMat()`、`cv2.recoverPose()`、`cv2.triangulatePoints()`

## 关键步骤
1. 每张视图提 SIFT，**相邻两帧**做比值检验匹配（相邻视角重叠最大）
2. 本质矩阵 + `recoverPose` 得到相对旋转与平移方向（尺度未知）
3. 用同一批点在前后两段三角化中的模长比，把各段尺度统一到同一基准
4. 位姿沿链累乘到第 1 个相机世界系，三角化所有内点并按重投影误差筛除离群点
5. 渲染点云，并与真值比较相机夹角

## 输入
6 张环绕视图（`view_01.png` … `view_06.png`，800×600）+ `intrinsics_gt.txt`

## 输出
合并点云两个视角、逐视角点云、原始视图概览

## 素材
`assets/view_*.png`：程序合成的"台面 + 10 个高低错落方块"场景，相机在半径 2.6 m 的圆弧上
每档转 14°（该角度由生成脚本固定，仅作对照，不参与计算）。

## 运行
```bash
cd Python && python3 demo.py --display
```
依赖 OpenCV（含 contrib）+ NumPy。

## 演示结果
| 文件 | 内容 |
| --- | --- |
| `output/recon_cloud.png` | 合并点云的正视与侧转 40° 渲染 |
| `output/recon_perview.png` | 每个视角分段三角化的结果 |
| `output/recon_views.png` | 6 张输入视图缩略图 |

实测：相邻帧旋转角 **13.6 / 14.0 / 14.0 / 14.4 / 13.1 度**，累积到首帧为
**13.6 / 27.6 / 41.6 / 55.9 / 69.0 度**，与真值（每档 14°）**误差 < 1°**；三角化 779 点。

## 已知局限（这条演示不够强，如实说明）
- **点云偏散**：本次场景物体尺度小、相机远，平移方向估计受近平面影响明显，
  各视角分段点云之间存在拼合残差，看不到清晰的方块轮廓，只看到点阵分布。
- **没有 BA**：尺度靠"模长比"估计，链式累积误差无法回环修正。
- 若要可用结果，需要增量式 SfM + 全局 BA（如 COLMAP 那套流程），已超出"只用 OpenCV 基础算子"的范围。
  因此本选题的可信部分是**位姿角度估计**，点云部分只作为流程演示。
