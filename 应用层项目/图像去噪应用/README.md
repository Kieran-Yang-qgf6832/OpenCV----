# 图像去噪应用

## 需求
对有噪图做去噪，并在"去噪强度"与"细节保留"之间给出可量化的比较。

## 作用

- **夜间监控**：高 ISO 噪声会拖垮后续检测。
- **医学/显微影像**：噪声影响计数与测量。
- **压缩前处理**：先降噪再编码，同码率下更干净。

适用边界：噪声模型要匹配（本例是高斯白噪声）；椒盐噪声应优先用中值，运动模糊要靠反卷积而不是去噪。

## 核心函数
`cv2.fastNlMeansDenoisingColored()`、`cv2.bilateralFilter()`、`cv2.medianBlur()`

## 关键步骤
1. 读干净图与加噪图（成对给出，才可量化）
2. 三种方法各跑一遍：非局部均值、双边滤波、中值滤波
3. 计算 PSNR / SSIM / 残留噪声标准差
4. 截取纹理区放大对照，观察是否把细节一起糊掉

## 输入
`clean.png`、`noisy.png`（1024×1024，成对）

## 输出
四宫格对比图与局部放大三联图，终端打印指标表

## 素材
`assets/clean.png` / `noisy.png`：水果静物，后者加了高斯噪声。

## 运行
```bash
cd Python && python3 demo.py --display
```
依赖 OpenCV（含 contrib）+ NumPy。

## 演示结果
| 文件 | 内容 |
| --- | --- |
| `output/denoise.png` | 干净 / 加噪 / 三种去噪结果 |
| `output/denoise_crop.png` | 葡萄纹理处局部放大（加噪 / NLM / 干净） |

实测指标：

| 方法 | PSNR | SSIM | 残留噪声 std |
| --- | --- | --- | --- |
| noisy | 20.41 dB | 0.339 | 16.38 |
| NLM | 24.18 dB | 0.670 | 11.23 |
| bilateral | 28.45 dB | 0.735 | 7.30 |
| median | **28.85 dB** | **0.808** | 7.88 |

## 实现要点
- **中值为什么赢**：噪声幅度大时中值对孤立的极值最有效，代价是细节略钝；
  NLM 更保边但在强噪声下残留明显。
- **NLM 的参数**：`h=7、hColor=7、templateWindow=7、searchWindow=21` 是速度与效果的折中，
  再调大收益有限但耗时翻倍。
- **别只看 PSNR**：还要看局部放大图，PSNR 高但纹理被抹平同样不可用。
