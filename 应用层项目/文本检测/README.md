# 文本检测

## 需求
在自然场景图（招牌、海报）中把文字区域找出来，并聚合成文字行。

## 作用

- **无障碍阅读**：先定位文字，再交给 OCR/语音播报。
- **场景理解**：路牌、门牌、价签的定位。
- **文档预处理**：拍歪的公告先裁出文字块。

适用边界：做得是"检测"不是"识别"；花体、强透视、低对比文字容易漏。

## 核心函数
`cv2.MSER_create()`、`cv2.morphologyEx()`、`cv2.findContours()`、`cv2.boundingRect()`

## 关键步骤
1. MSER 抽取稳定的极值区域作为候选文字块
2. 按高度、宽高比过滤（去掉斑点与长条）
3. 水平方向闭运算把同一行的字连成一条
4. 输出两层框：绿色为单块，橙色为聚合后的文字行

## 输入
一张招牌照片（`signboard.png`，640×1024）

## 输出
文字块 + 文字行框选图，以及候选区域的二值掩膜

## 素材
`assets/signboard.png`：深底浅字的"视觉实验室 / VISION LAB · OpenCV / 文本检测与识别演示"招牌。

## 运行
```bash
cd Python && python3 demo.py --display
```
依赖 OpenCV（含 contrib）+ NumPy。

| 文件 | 内容 |
| --- | --- |
| `output/text_regions.png` | 990 个候选块聚合为 **4 条文字行**，行框带尺寸标注 |

## 实现要点
- **为什么不用 ERFilter**：`cv2.text` 的 ERFilter 需要 `trained_classifierNM1/NM2.xml`
  两个分类器文件，OpenCV 发行包里不带、opencv_extra 也没有，所以改用内置 MSER，
  保持"只用 OpenCV 随包能力"。
- **候选数很多是正常的**：MSER 对每个对比度稳定的区域都给一个候选，过滤才是关键；
  宽高比 (0.16~6) 与高度 (10~200 px) 是最有效的两个筛子。
- **行聚合核大小**：`(25, 3)` 的横向核刚好把中文字间距连起来又不跨行；
  字号变化大时要按文字高度自适应。
