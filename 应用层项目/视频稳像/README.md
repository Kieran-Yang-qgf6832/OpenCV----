# 视频稳像

## 需求
估计手持拍摄视频的逐帧抖动轨迹，平滑后反向补偿，输出稳定画面。

## 作用

- **手持/车载录像**：去掉高频抖动，观感与编码效率都更好。
- **监控抖动修正**：风吹支架导致的画面晃动。
- **后续算法前置**：抖动的视频会让帧差、跟踪、拼接全部变差。

适用边界：只处理平移抖动（相位相关）；带旋转/缩放的抖动需要估计仿射或单应，代价更高。

## 核心函数
`cv2.phaseCorrelate()`、`cv2.warpAffine()`

## 关键步骤
1. 相邻帧灰度做相位相关，得到逐帧位移，累加成运动轨迹
2. 轨迹做滑动平均（半径 15）得到"理想轨迹"
3. 补偿量 = 理想轨迹 − 实际轨迹，用 `warpAffine` 平移回位，并裁掉边缘无效区
4. 左右并排输出原始/稳像视频，另画原始与平滑后的轨迹曲线

## 输入
`shaky.mp4`（100 帧，1280×720）

## 输出
稳像对照视频、对比图、轨迹曲线

## 素材
`assets/shaky.mp4`：走廊画面叠加了幅度数十像素的随机平移抖动。

## 运行
```bash
cd Python && python3 demo.py --display
python3 demo.py --radius 15
```
依赖 OpenCV（含 contrib）+ NumPy。

## 演示结果
| 文件 | 内容 |
| --- | --- |
| `output/stabilized.mp4` | 左原始 / 右稳像，并排对照 |
| `output/stabilize_compare.png` | 中间帧对照 |
| `output/stabilize_curve.png` | 原始轨迹（红）与平滑轨迹（绿） |

实测：帧间位移 std 从 **9.25 / 8.83 px** 降到 **0.51 / 0.38 px**（下降 **95%**），
原始轨迹最大偏移 28 px。

## 实现要点
- **指标口径要对**：一开始用"轨迹残差 std"当指标，补偿前后数值一样（残差定义没变），
  换成"帧间位移波动"才能体现补偿效果。
- **边界处理**：`BORDER_REPLICATE` + 统一裁边，避免画面晃动时露出黑边。
- **平滑窗口**：半径太小去不干净抖动，太大则把有意的摇镜也抹平。
